# DIPLO-CLOUD-USUARIO-SERVICE
Implementación de cliente en microservicio de usuario
## Proyecto
Implementation of cliente microservice for the pixup application. The cliente microservice provides the following functionalities:
- Registro Cliente
- Nombre
- Dirección
- email
